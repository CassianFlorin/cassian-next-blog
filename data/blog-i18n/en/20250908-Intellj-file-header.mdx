# Customizing IntelliJ IDEA File Headers

## 🎯 Background Information

In the software development process, the **File Header** contains the definitions and original intent of the project and the file. A well-written File Header helps future developers quickly understand the design intent and background information of the code.

### The Purpose of the File Header

The file header, as the first part of a file, typically contains the following basic information:

- **Author Information** - Identifies the creator of the code
- **Creation Date** - Records the date the file was created
- **File Description** - Describes the file's functionality and purpose
- **Copyright Notice** - Protects intellectual property
- **Version Information** - Track changes to the file
- **Project or Module Name** - Identify the project to which it belongs
- **Contact Information** - Facilitate future communication

By standardizing file headers, team members can quickly understand the context in which a file was created and who authored it, thereby improving code maintenance efficiency—especially when working on complex or long-standing projects.

## 📝 File Header Example

The following is an example of a standard Java file header:

```java
/**
 * Author: CassianFlorin
 * Created: 2025-05-20
 * Description: This class implements the user authentication logic.
 * Version: 1.0.0
 * License: MIT License
 */
public class AuthService {
    // Class implementation
}
```

## ⚙️ File Header Configuration Steps

### 1. Go to the configuration screen

In IntelliJ IDEA, navigate to the settings using the following path:

```
File → Settings → Editor → File and Code Templates → Includes → File Header
```

### 2. Configuration Interface Overview

- **File and Code Templates**: File and code template settings
- **Includes**: Included template files
- **File Header**: File header template

## 🚀 Dynamically Generating Headers Using Groovy Scripts

To distinguish between the file headers for personal projects and corporate projects, I used a Groovy script to dynamically generate different header information.

### Configuration Script

```groovy
#if(${PACKAGE_NAME.startsWith("[公司的包路径]")})
/**
 * @Author [公司要求的名称]
 * @Email [公司邮箱]
 * @Date ${DATE} ${TIME}
 */
#else
/**
 * @Author CassianFlorin
 * @Email flowercard591@gmail.com
 * @Date ${DATE} ${TIME}
 */
#end
```

### Script Description

- **`${PACKAGE_NAME}`**: Retrieve the package name of the class currently being created
- **`${DATE}`**: Current date
- **`${TIME}`**: Current time
- **Conditional Check**: Determine whether it is a company project or a personal project based on the package prefix

### How It Works

In enterprise-level development, package names typically follow the "reverse domain name" convention (e.g., `com.company.project`). Therefore, different project types can be distinguished by examining the package name prefix, allowing the corresponding file header information to be generated.
