### Maven Dependencies

Add the Sensorsan SDK dependency to the project's `pom.xml`:

```xml
<!-- 引入神策分析 SDK -->
<dependency>
    <groupId>com.sensorsdata.analytics.javasdk</groupId>
    <artifactId>SensorsAnalyticsSDK</artifactId>
    <version>3.6.8</version>
</dependency>
```

## ⚙️ Configuration Instructions

### Configuration Property Class

The project uses the `SensorsDataProperties` class to manage Sensors Analytics-related configurations:

```java
@RefreshScope
@Data
@Component
@ConfigurationProperties(prefix = "sensorsdata")
public class SensorsDataProperties {

    /**
     * 神策服务地址
     */
    private String serverUrl;

    /**
     * 埋点模式
     */
    private String trackMode;

    /**
     * 神策事件名称
     */
    private String eventName;

    /**
     * 批量发送配置
     */
    private BatchMode batch;

    @Data
    public static class BatchMode {
        /**
         * 快速批量发送模式"每次发送"条数阈值
         */
        private Integer bulkSize;

        /**
         * 缓存队列最大条数
         */
        private Integer maxCacheSize;

        /**
         * 超时时间（秒）
         */
        private Integer timeoutSeconds;
    }
}
```

### Tracking Mode Enumeration

The supported tracking modes are defined in `SensorsTrackModeEnums`:

```java
public enum SensorsTrackModeEnums implements EnumLookUp<String> {
    DEBUG("debug", "测试上报"),
    BATCH("batch", "批量模式"),
    FAST_BATCH("fast_batch", "快速批量模式");
}
```

        try {
