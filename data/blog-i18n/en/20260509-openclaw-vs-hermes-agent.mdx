## 🔌 Plugin Ecosystem: Each Has Its Own Strengths

<div className="mb-8 grid grid-cols-1 gap-6 md:grid-cols-2">
  <div className="rounded-lg border border-blue-200 bg-blue-50 p-6 dark:border-blue-800 dark:bg-blue-900/20">
    <h4 className="mb-4 text-lg font-semibold text-blue-900 dark:text-blue-200">
      OpenClaw’s Plugin System
    </h4>
    <ul className="space-y-2 text-sm text-blue-700 dark:text-blue-400">
      <li>✅ <strong>Plugin SDK</strong>: Complete plugin-sdk public contract</li>
      <li>✅ <strong>Manifest-first</strong>: No runtime loading during cold start</li>
      <li>✅ <strong>Third-party plugins</strong>: Distributed via npm</li>
      <li>✅ <strong>Plugin Hot Reloading</strong>: Supports runtime loading</li>
      <li>✅ <strong>60+ Built-in Skills</strong></li>
    </ul>
  </div>

{' '}
<div className="rounded-lg border border-purple-200 bg-purple-50 p-6 dark:border-purple-800 dark:bg-purple-900/20">

    The Hermes Agent’s Skill System
  </h4>
  <ul className="space-y-2 text-sm text-purple-700 dark:text-purple-400">
    <li>
      ✅ <strong>Skill System</strong>: 50+ built-in skills
    </li>
    <li>
      ✅ <strong>Hot Editing of Skills</strong>: Create, edit, and delete at
      runtime
    </li>
    <li>
      ✅ <strong>skill_manage Tool</strong>: More Flexible Skill Management
    </li>
    <li>
      ✅ <strong>Third-Party Plugins</strong>: In-repo + Marketplace
    </li>
  </ul>
</div>
