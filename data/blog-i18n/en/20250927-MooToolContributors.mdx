# I Became a MooTool Contributor Today

Long time no see! It’s been a while since I last updated my blog!

Actually, I've been so busy with my day job lately that I haven't even had time to write blog posts.

It wasn't until recently that I discovered an open-source project on GitHub called MooTool, a tool developed in Java.

What was the catalyst? The catalyst was that I had used a "Text Diff" (text comparison) feature in other tools.

But this project doesn't have that feature, and since I'm interested in starting to contribute to open source, I'm well aware that these tools are already available. Still, building it myself would be a way to satisfy my own sense of accomplishment.

I hope more and more people will come to like this tool.

<Callout emoji="🎉">
  Today, I officially became a contributor to <strong>MooTool</strong>! This is a Java-based open-source tool,
  and I’ve added support for <strong>Text Diff (text comparison)</strong>, a feature I use frequently.
  I hope it will be helpful to more people, and I welcome everyone to join in and contribute.
</Callout>
