# Today I Became a MooTool Contributor

Long time no see! It’s been a while since I last updated my blog!

To be honest, I’ve been extremely busy with my day job lately—so busy that I haven’t even had time to write blog posts.

Until recently, when I discovered an open-source project on GitHub called MooTool—a tool developed in Java.

What sparked this? It was because I needed a “Text Diff” (text comparison) feature in another tool I was using.

However, this project didn’t have that feature. Since I was interested in starting to contribute to open source—and I’m well aware that such tools already exist—I figured building it myself would be a way to satisfy my own sense of accomplishment.

I hope more and more people will come to like this tool.

<Callout emoji="🎉">
Today, I officially became a contributor to <strong>MooTool</strong>!This is an open-source tool built on Java,
  and I’ve added the <strong>Text Diff (text comparison)</strong> functionality that I frequently use.
  I hope it can help more people, and I welcome everyone to join in and contribute.

</Callout>
